2026-11-05，Asia/Shanghai。C8 已完成发布候选的本机隔离启动和首轮 MES 只读检查。正式运行实例部署与业务验收分别记录。

## 候选范围

候选代码基于 `bf2d713`，包含本轮检验历史兼容修复。隔离实例使用独立会话、检查点和事务库，绑定本机回环地址并使用临时 MCP 鉴权。Web 首页返回 200，未带令牌的 MCP 初始化返回 401。鉴权后的初始化、工具列表和质量能力目录均通过。

候选质量目录有 82 个工具，82 个输入对象均关闭额外字段。六个质量写入和审计入口均在 Agent 中要求确认。八条业务问法覆盖审批、签名、事件草稿、返工与报废、检验历史、SPC 和提交准备，均选中预期入口，查询问法均保持执行器不可见。此项检查验证选工具范围和确认策略，真实模型的多轮选择仍需在目标实例验收。

首轮全量回归发现旧检验核对调用可缺少计划类型。修复后这类调用继续执行通用字段核对，批采样专属核对仍要求明确的原计划类型。179 项定向回归通过。修复后再次隔离启动，82 个工具的输入定义摘要与首轮一致；鉴权后的 MCP 实际读取了 C4 检验明细和 C6 就绪诊断，12 次 MES 请求均在只读保护下成功完成。

修复后的全项目离线回归通过 4586 项测试和 2 项子测试，真实 HTTPX 网络尝试为 0。完整结果见本地 `docs/quality-fixtures/c8-preflight-final-junit.xml` 和 `docs/quality-fixtures/c8-preflight-final-network.json`。

- 本机默认 Web 端口 8030 无监听。当前配置的外部 MCP 为关闭，未配置令牌。隔离候选已正常停止。
- MES 只读检查共 23 次请求，均返回成功，保护器拦截 0 次。已处置的 C4 返工批读取完整，整批 OK 前置仍被拦住。原批可见两条采样汇总，指定原汇总可展开一条样本明细。

## 正式发布验收顺序

1. 明确目标实例、候选版本、启动方式、维护时段和可回滚版本。记录目标 MES 环境与确认策略。部署前保留现有配置、会话、原质量事务库和锁位置。
2. 在目标进程验证 Web 入口及实际 Agent 工具目录。若发布范围包括外部 MCP，按实际配置验证拒绝未授权访问、鉴权初始化、工具列表与客户端确认流程。Agent 确认与 MCP 接入鉴权分别记录。
3. 复跑本轮业务问法，并在目标实例核对真实多轮选择。只读问题应停在查询和证据；执行问题应先返回原计划和确认，核对摘要与环境。
4. 使用明确的隔离 MES 样本执行获准的现场用例。正向检查持久状态及父子事务，异常检查拒绝、未知占用及防重复。由原阶段的验收记录确定各业务范围通过状态。
5. 若候选无法通过启动、鉴权、目录或关键只读检查，按原部署流程恢复前一版本和配置，保留原质量事务库及审计记录。按恢复后的实例重跑同一组检查。
