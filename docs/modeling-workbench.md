# 建模工具台

入口：重启应用后从左侧“建模工具台”进入 `/modeling`。沿用现有工作台配色，提供桌面和窄屏布局。新增 Web 接口只读取业务数据或保存本地预览计划，不直接执行 Camstar 写入。

## 六项功能

| 功能 | 本轮提供 | 范围 |
|---|---|---|
| 路线可视化 | 名称/版本查 Workflow 或 Product；显示步骤、普通路径、可解析的返工目标、展开的子流程；点击节点查看 Spec、Operation 及高级配置 | 条件表达式不求值；不能解析的高级目标保留在节点证据中，不伪造连接 |
| 完整性检查 | 引用解析、普通路径目标检查、普通路径下不可达步骤、入口和循环提示、Spec/Operation 引用一致性 | 未返回数据记为未知；合法返工环不直接认定为错误 |
| 版本比较与路线模板 | Product 返回字段比较；Workflow 具名步骤/Gates 差异；线性路线模板复制到新名称/版本；预览中新增、删除、重排、修改步骤并重新校验 | 不支持完整 Product 克隆；模板不复制所有对象属性，复杂分支/返工/子流程/调度配置会阻止复制。不同版本比较为非事务读取 |
| Excel/CSV 映射向导 | 工作表、表头行选择；字段映射建议和手动调整；前八行样本；全部行校验和逐行错误；展示原步骤与替换范围；恢复最近计划 | 最多 10 MB、200 行；字段自动匹配仅按名称，必须核对；编辑后来源行按新表格编号 |
| 工单现场 | 产品、计划数量、容器位置、工序分布、挂起/返工字段和最近历史；前后翻页 | 分布为当前页；完成数量、完成率、未返回状态保持未知 |
| 容器追溯 | 可点击关系图、关系证据、深度选择、关联容器继续展开、直接历史时间线及翻页 | 明确显示遍历上限和失败；未知交叉引用不递归；真实非空拆分/合并/返工验收仍待补充 |

## 预览与确认执行

路线复制与导入统一生成已有的不可变计划（环境绑定、摘要校验、一小时有效期、一次领取、预检与本地锁）。界面链接仅把计划 ID/摘要带入对话草稿，不自动发送，也不自动写入。用户发送草稿后使用现有 Agent 确认流程执行同一计划。

预览中修改步骤后旧执行链接失效，重新校验才生成新的计划。旧计划仍保持不可变，不由前端重写。执行记录新增动作关联的路线、步骤名称和动作类型，按表格行展示状态；新增请求成功不等同整条路线核对成功。超时继续标为未知，不自动重试。旧日志缺少行关联证据时明确显示“尚无该行写入证据”。

## MCP 能力

- `check_modeling_integrity`：读取 Workflow 或 Product 的完整性证据。
- `compare_modeling_versions`：比较返回范围内的版本差异。
- `preview_workflow_copy`：生成线性路线模板计划。

三者均为只读/预览能力，已加入显式工具目录和按需路由。原 `preview_workflow_import` 增加 CSV 与可选 `header_row`（零起始）支持。
