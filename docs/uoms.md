# UOM 计量单位

工具位于 `reference` 组：`list_uoms` 分页查询、`get_uom` 详情、`create_uom` 新建、`update_uom` 修改。

2026-10-31 已只读核实现场 Swagger 和列表/详情，现场现有单位为 EACH、UNIT。接口契约归档于 `Swagger/modeling-uoms-swagger.json`。尚未在现场执行真实新增或修改验收。

维护范围为名称、描述、备注。创建前检查名称占用；更新须实际16位 InstanceID 及 expected_name，核对冻结和变更管理锁。省略参数保持原值；描述/备注传空字符串可清空。单次 POST/PUT 后读取实际对象并比较所请求字段；只有提交已确认且字段匹配才返回 verified=true。超时或结果未知不能自动重发，同名或同值回读不单独证明本次写入成功。

需要单位的定义先查询并使用准确名称。缺失时，按用户明确的新增需求创建并核验，再引用。V、mV、Ω、mΩ、mm、kg 等只是可能的业务名称，工具不批量预置、不猜测单位或比例。UOM 名称维护不建立换算规则；重命名影响全局引用，不能当作历史值转换。
